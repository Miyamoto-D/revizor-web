# Ревизор: Дело в городе N

Веб-версия образовательной игры по комедии Н. В. Гоголя «Ревизор».

**Играть:** https://miyamoto-d.github.io/revizor-web/

Нужен браузер с WebGL 2 (современные Chrome, Edge, Firefox, Safari).
Управление: WASD или стрелки, E — говорить, клик или тап — идти; на телефоне — джойстик и кнопка.
Прогресс сохраняется в браузере.

Здесь лежит только собранная игра; она обновляется скриптом `tools/deploy_web.py` из основного проекта.
